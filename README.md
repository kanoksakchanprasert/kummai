# คุ้มไหม? (KumMai) — เปรียบเทียบความคุ้มค่า

Web app สำหรับเปรียบเทียบตัวเลือกสินค้าหลายตัว แล้วบอกว่าตัวไหนคุ้มที่สุดเมื่อเทียบกับเงินที่จ่ายจริง

## วิธีใช้
1. กรอกชื่อ/ร้าน, ปริมาณต่อชิ้น + หน่วย, จำนวน (เว้นว่าง = 1), ราคารวม และค่าอื่นๆ (ค่าส่ง ค่าธรรมเนียม ฯลฯ — ส่วนลดใส่เป็นค่าติดลบ)
2. ผลคำนวณอัปเดตทันทีขณะพิมพ์

## วิธีคำนวณ
```
ปริมาณรวม   = ปริมาณต่อชิ้น × จำนวน
ยอดจ่ายจริง = ราคารวม + ค่าอื่นๆ
ราคาต่อหน่วย = ยอดจ่ายจริง / ปริมาณรวม (แปลงเป็นหน่วยฐานแล้ว)
```
- แปลงหน่วยอัตโนมัติภายในหมวดเดียวกัน: น้ำหนัก (มก./ก./กก.), ปริมาตร (มล./ล.), จำนวน (ชิ้น/ซอง/ขวด/กล่อง/โหล), ความยาว (ซม./ม.)
- ตัวที่ราคาต่อหน่วยต่ำสุดคือคุ้มที่สุด ส่วนตัวอื่นแสดง % ที่แพงกว่า และเงินที่จ่ายเกินเมื่อเทียบปริมาณเท่ากัน
- ตัวเลือกที่ใช้หน่วยต่างหมวดจากส่วนใหญ่จะถูกระบุว่า "เทียบไม่ได้"

## รันในเครื่อง
เปิด `index.html` ในเบราว์เซอร์ได้เลย ไม่ต้อง build

## Deploy บน GitHub Pages
1. Push ไฟล์ทั้งหมดขึ้น repo บน GitHub (branch `main`, ไฟล์อยู่ที่ root)
2. ไปที่ **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**
   - Branch: `main` / `(root)` → Save
3. รอ 1–2 นาที แล้วเปิด `https://<username>.github.io/kummai/` (ตั้งชื่อ repo ว่า `kummai`)
